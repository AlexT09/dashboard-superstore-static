# Proyecto Sample Superstore

**Factores que explican el nivel de ventas · Análisis exploratorio de datos (EDA)**

*Proyecto: Alex Teran y David Estrada*

## El problema

Sample Superstore es un conjunto de datos de muestra de una gran cadena minorista —una simulación
con fines analíticos— sobre el que se realiza un análisis exploratorio de datos (EDA) para ofrecer
información que ayude a la empresa a aumentar sus beneficios y, al mismo tiempo, minimizar sus
pérdidas.

## Pregunta problema
